# 交互与组件关系表达原型

本原型验证两个问题：用户是否能在原生 Excalidraw 画板中通过两次选择建立清晰的交互关系；用户是否能把图稿位置关联到原生组件参考卡，同时让模型获得稳定的结构化数据。

运行 `pnpm prototype:design-relations`，浏览器会打开原生画板实验页。

原型状态仅保存在内存中，不会修改 Dockyard 项目数据。顶部工具栏增加“交互”和“组件关联”两个实验工具；画面中的箭头、标签、虚线及组件参考卡都是真实 Excalidraw 元素。

组件关联会先选择画板位置，再打开临时组件侧栏。侧栏包含文字检索、来源筛选、草图检索、候选列表和真实效果预览，并提供“放到画板预览”与“建立组件关联”两个操作。

`example-intent.json` 是完成示例对应的模型可读数据，`result.png` 是实际浏览器操作后的截图。
