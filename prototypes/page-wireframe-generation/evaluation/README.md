# 页面原型生成陌生需求实验

本实验用三条接近日常表达、未包含布局答案的需求，检查技能能否保留业务关系，并给出三种有意义的页面结构。

## 测试输入

1. 电商订单详情：“我想做一个电商订单详情页面，能看到订单现在到哪一步了、买了什么、收货信息和付款情况，也要方便客服处理退款或者联系用户。”
2. 销售数据分析：“这是一个销售数据分析工作台，我主要想看最近的销售趋势、几个关键指标，还有不同地区和商品的表现，发现异常以后能继续往下看。”
3. 手机预约挂号：“我要做一个手机上的预约挂号页面，用户要选择科室、医生和时间，最好能一直知道自己已经选了什么，最后确认预约。”

每条输入生成 `A/B/C`（三种方案）三个独立的 `.excalidraw`（原生图稿）文件，并通过 Dockyard 的实际桌面画板导入和截图。截图中的文字均完整显示，图稿元素可以独立选择和编辑。

运行：`pnpm prototype:page-wireframe:evaluate`
