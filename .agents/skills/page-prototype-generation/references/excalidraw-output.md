# 原生图稿规则

## 中间元素

先规划画布和坐标，再写元素。模型只需确定稳定标识、类型、位置、尺寸、文字、分组和基础样式；转换程序负责补齐 Excalidraw 必需字段。

页面大区域使用矩形和独立标题文字。大区域不使用居中绑定文字，以免覆盖内部内容。重复数据使用简化行。

## 尺寸

- 正文字号至少 16，方案标题至少 24。
- 中文文字宽度按每个全角字符约一个字号计算，并额外保留 24 像素余量。
- 兄弟区域间距至少 32 像素。
- 页面外围保留编辑器控件和后续批注需要的空白。
- 合并图用于比较，独立图用于评审。

## 样式

使用白色、黑色和中性灰，保持平面、低保真。用区域比例、分隔和留白表达层级。

## 原生结构

顶层包含 `type: "excalidraw"`、`version: 2`、`source`、`elements`、`appState` 和 `files`。元素使用唯一且稳定的字符串 `id`，所有图形与文字保持独立可编辑。

## 视觉检查

真实渲染后逐项检查：

1. 文字是否完整且属于正确区域。
2. 区域是否重叠，边框是否穿过文字。
3. 页面结构是否能在数秒内看懂。
4. 三个方案是否具有真实结构差异。
5. 编辑器工具是否遮挡标题或主要页面。

发现一项问题就修改原生元素并重新截图，不以 JSON 合法代替视觉检查。
