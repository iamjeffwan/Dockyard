# 使用带 Dockyard 数据的增强版 Excalidraw 文件

Dockyard 第一版设计意图持久化采用单个增强版 `.excalidraw` 文件：原型元素、交互关系和组件关联继续使用 Excalidraw 原生元素与绑定能力，Dockyard 关系事实写入元素的 `customData`（自定义数据），顶层只保留 Dockyard 数据结构版本和必要索引。这样重新打开时可以先恢复原生画板，再根据稳定标记重建组件运行时预览；同时仍可导出移除 Dockyard 数据的普通 `.excalidraw` 文件供其他工具使用。组件定义编号（`componentKey`）与元素编号、静态资源编号分离，避免未来迁移到 CDN（内容分发网络）时破坏画稿身份。

## Consequences

- Dockyard 只对自己保存的增强版文件保证关系数据完整；普通版导出不承诺可恢复组件关联。
- 组件卡片的坐标和尺寸以原生元素为事实来源，关系数据只引用元素编号，不重复保存几何数据。
- 关系恢复只读取 Dockyard 专用标记，不根据颜色、虚线或箭头形状猜测普通箭头的含义。
- 第一版不保存项目级视觉约束、组件运行时版本或临时交互状态。
